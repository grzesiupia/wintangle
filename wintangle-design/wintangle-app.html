Tile windows with hotkeys. Keyboard only.

wintangle is a tray-first window manager for Windows 11 — 16 fixed slots, 18 rebindable chords, gaps that apply live, and a single settings window. No mouse required.

Tray-first

The whole app lives in the tray.

Right-click the icon to tile any window into one of the 16 slots, hop monitors, ignore an app, or flip autostart. The menu is rebuilt on every open, so every binding you see here is live.

  • 16 slots halves, quarters, thirds, sixths
  • 18 chords every one rebindable
  • Balloons only when a window can't be moved
